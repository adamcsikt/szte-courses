# Scripting Languages - University Assignments

This repository contains my assignments, homework, and practice tasks for the "Scripting Languages" university course. The course focused on modern scripting fundamentals, algorithms, and problem-solving using **JavaScript** and **TypeScript**.

### The "Bíró" Automated Grading System
All code in this repository was written strictly to be evaluated by the university's automated testing and grading system ("Bíró"). 

Because of this environment, the solutions are heavily focused on:
*   Strict algorithmic accuracy and passing hidden edge-cases.
*   Precise Standard Input/Output (stdio) handling.
*   Standalone script execution rather than complex project architectures.

### Structure
The files are primarily organized by weeks/practices:

*   **JavaScript (`.js`)**: Early weeks (`gyak_2`, `fourth`, `fifth`, `sixth`, `seventh`).
*   **TypeScript (`.ts`)**: Later assignments focusing on static typing (`nine`, `eleven`).
*   **`home/`**: Contains specific, more complex algorithmic homework challenges, such as:
    *   Array chunking logic (`arrayChunk.js`)
    *   String manipulation and ciphers (`cipherShift.js`, `longestUniqueSubString.js`)
    *   Multidimensional array handling (`matrixRotate.js`, `nestedSum.js`)

### Tech Stack
*   JavaScript (Node.js environment)
*   TypeScript
